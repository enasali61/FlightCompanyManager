Airplane Management System (CRUD App)
A simple Windows Forms application built with .NET to manage an airline company’s basic data, including airplanes, airlines, employees, and flight routes

@Technologies Used@
C#

.NET 8

Windows Forms

SQL Server

Entity Framework Core (EF Core) for database operations

 //Features//
Insert, update, and delete records for:

Airplanes

Airlines

Employees

Flight routes

Clean and intuitive user interface built with Windows Forms

Uses EF Core to connect to and interact with the SQL Server database

Setup Instructions
Ensure SQL Server is installed and running.

Create the necessary database and tables (not included in this project).

Update the connection string in the app's configuration to point to your SQL Server instance.

Open the solution in Visual Studio.

Build and run the app to start managing the airline data.
